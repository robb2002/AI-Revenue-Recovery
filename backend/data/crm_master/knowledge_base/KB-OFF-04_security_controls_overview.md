# Pearson Security Controls Overview

Excerpts are short quotations from the cited page, collected on 2026-11-04. The summaries are our own words.

## Framework alignment
Summary (our words): the page describes a security programme aligned to recognised frameworks.

> "Our security program is designed in alignment with recognized frameworks and standards, including the NIST Cybersecurity Framework (CSF)." ([source](https://www.pearson.com/privacy-center/security-controls.html))

## Certifications and regulations
Summary (our words): the page says controls "support compliance" with several certifications and regulations "where applicable". It does not state that every product holds each certification.

> "Our controls support compliance with applicable certifications and regulations such as SOC 2, ISO/IEC 27001, PCI DSS, FedRAMP, and GDPR where applicable." ([source](https://www.pearson.com/privacy-center/security-controls.html))

## Consistency across the organisation
> "We maintain a consistent control framework across the organization, with additional requirements applied based on product, system, and regulatory requirements." ([source](https://www.pearson.com/privacy-center/security-controls.html))

## Encryption
> "We use industry-standard encryption to protect data both at rest and in transit." ([source](https://www.pearson.com/privacy-center/security-controls.html))

## Monitoring
> "We use automated tools and monitoring processes to identify potential security threats and anomalous behavior across our environment." ([source](https://www.pearson.com/privacy-center/security-controls.html))

## How to word this with a customer (illustrative guidance)
- Say that Pearson publishes a security overview and quote it. Do not say that a named product is "SOC 2 certified" or "ISO 27001 certified" unless a product-specific document confirms it.
- Send customer security questionnaires to the security team (see KB-SEC-01).

## Not covered by this document
- Which certifications apply to which product, and their dates.
- Audit reports, penetration test results, or recovery targets.
- Where a specific product's data is hosted (see KB-OFF-05).
